سؤالات متداول

پیش از شروع چه چیزی لازم است؟

برای راه‌اندازی، حساب تلگرام، یک کارت مقصد و گوشی دریافت‌کننده پیامک بانکی کافی است.

بلوپی اطلاعات کارت خریدار را ذخیره می‌کند؟

خیر. پرداخت مستقیم به کارت مقصد انجام می‌شود و بلوپی رمز، CVV2 یا اطلاعات ورود بانکی خریدار را دریافت نمی‌کند.

آیا بدون اتصال API هم می‌توان فاکتور ساخت؟

بله. پذیرنده می‌تواند فاکتور دستی را مستقیماً از داخل ربات ایجاد و لینک آن را برای مشتری ارسال کند.

برای هر فروشگاه چند API ساخته می‌شود؟

هر فروشگاه دقیقاً یک API Key فعال دارد. در صورت نیاز، کلید قبلی بازنشانی و با کلید جدید جایگزین می‌شود.

اگر Callback فروشگاه در دسترس نباشد چه می‌شود؟

بلوپی تحویل Callback را تا سه مرتبه با فاصله زمانی مشخص تکرار می‌کند و پاسخ‌های HTTP 2xx را موفق در نظر می‌گیرد.

آماده راه‌اندازی هستید؟

اولین فاکتور پرداخت خود را همین حالا بسازید.

ثبت‌نام، کارت مقصد، وبهوک پیامک و API فروشگاه از داخل ربات مدیریت می‌شوند.
