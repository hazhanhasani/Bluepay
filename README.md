# BluePay Gateway Bot v0.5.9

بلوپی یک زیرساخت واسط پرداخت مستقیم برای ربات‌ها، وب‌سایت‌ها و چند فروشگاه مستقل است. سامانه فاکتور صادر می‌کند، مبلغ یکتا می‌سازد و پرداخت را با پیامک بانکی تطبیق می‌دهد.


## تغییرات نسخه 0.5.9

- افزودن عضویت اجباری قابل مدیریت از مرکز مدیریت سامانه
- امکان تعریف چند کانال عمومی یا خصوصی برای عضویت اجباری
- بررسی عضویت واقعی با `getChatMember` و جلوگیری از ورود تا تکمیل همه کانال‌ها
- الزام مدیر بودن ربات در کانال هنگام ثبت کانال اجباری
- افزودن احراز هویت با دکمه رسمی «ارسال شماره تلگرام من»
- پذیرش شماره فقط در صورتی که `contact.user_id` با Telegram ID فرستنده برابر باشد
- رمزنگاری شماره کامل و نمایش فقط چهار رقم پایانی در حساب و پنل مدیریت
- امکان فعال یا غیرفعال‌کردن مستقل عضویت اجباری و احراز شماره
- امکان لغو احراز شماره هر پذیرنده توسط مدیر برای احراز مجدد
- مهاجرت خودکار دیتابیس برای نصب‌های قبلی بدون نیاز به SQL دستی

### مسیر مدیریت دسترسی

```text
مرکز مدیریت سامانه ← عضویت و احراز هویت
```

برای کانال عمومی، `@username` کافی است. برای کانال خصوصی باید شناسه عددی و لینک دعوت به‌شکل زیر ثبت شود:

```text
-1001234567890 | https://t.me/+InviteCode
```

مدیر اصلی از محدودیت دسترسی معاف است تا در صورت حذف کانال یا از دست رفتن دسترسی ربات، امکان اصلاح تنظیمات باقی بماند.

## مدیریت ظاهر و کلیدها

مسیر مدیریت:

```text
مرکز مدیریت سامانه ← ظاهر و کلیدهای ربات
```

رنگ‌های رسمی قابل استفاده برای کلیدهای تلگرام عبارت‌اند از آبی (`primary`)، سبز (`success`)، قرمز (`danger`) و حالت پیش‌فرض. در قالب هوشمند، رنگ هر کلید بر اساس نوع عملیات انتخاب می‌شود.

در بخش «فهرست کامل ایموجی‌ها»، سامانه تمام ایموجی‌ها و نمادهایی را که واقعاً در متن‌ها و کلیدهای ربات استفاده شده‌اند استخراج و صفحه‌بندی می‌کند. کنار هر مورد، تعداد استفاده و وضعیت ثبت جایگزین نمایش داده می‌شود. مدیر با انتخاب هر ایموجی، نسخه Telegram Custom Emoji همان مورد یا شناسه عددی آن را ارسال می‌کند. سامانه پیش از ذخیره، شناسه را با API تلگرام بررسی و روی یک کلید آزمایشی نمایش می‌دهد.

جایگزینی به‌صورت دقیق انجام می‌شود؛ برای مثال تنظیم نسخه پرمیوم `💳` فقط تمام نمونه‌های همان `💳` را در کلیدها و متن‌های قالب‌بندی‌شده جایگزین می‌کند. بخش‌های فنی داخل `code` و `pre` دست‌نخورده باقی می‌مانند.

> استفاده از Custom Emoji روی کلیدها تابع شرایط تلگرام است؛ معمولاً مالک ربات باید Telegram Premium داشته باشد یا ربات شرایط مجاز اعلام‌شده توسط تلگرام را داشته باشد.

## ساختار فروشگاهی

```text
حساب پذیرنده
├── فروشگاه اول
│   ├── یک کلید API اختصاصی
│   └── Callback و Secret مستقل
└── فروشگاه دوم
    ├── یک کلید API اختصاصی
    └── Callback و Secret مستقل
```

هر پذیرنده می‌تواند حداکثر ۲۰ فروشگاه داشته باشد و هر فروشگاه دقیقاً یک کلید API اختصاصی دارد.

مسیر مدیریت:

```text
اتصال و API ← فروشگاه‌ها و APIها
```

هنگام ثبت فروشگاه، کلید API اختصاصی به‌صورت خودکار صادر می‌شود. کلید کامل فقط همان یک‌بار نمایش داده می‌شود. بازنشانی کلید، کلید قبلی را فوراً باطل می‌کند.

## API فروشگاهی

هر کلید API به یک فروشگاه متصل است و فروشگاه از روی کلید تشخیص داده می‌شود؛ نیازی به ارسال `store_id` در بدنه نیست.

ساخت فاکتور:

```http
POST /api/v1/invoices
X-API-Key: gw_xxx
Content-Type: application/json
```

```json
{
  "amount_toman": 200000,
  "order_id": "ORDER-1001",
  "description": "اشتراک یک‌ماهه",
  "fee_mode": "split",
  "ttl_minutes": 30
}
```

پاسخ شامل این اطلاعات فروشگاهی نیز هست:

```json
{
  "store_id": 12,
  "store_code": "ST-A1B2C3D4",
  "store_name": "فروشگاه اصلی",
  "api_key_id": 31
}
```

استعلام و لغو فقط با یکی از کلیدهای همان فروشگاه مجاز است:

```http
GET /api/v1/invoices/{payment_id}
POST /api/v1/invoices/{payment_id}/cancel
X-API-Key: gw_xxx
```

## قرارداد فعلی API

### مقادیر `fee_mode`

- `merchant`: کارمزد کامل از کیف پول پذیرنده تسویه می‌شود و چیزی روی مبلغ مشتری اضافه نمی‌شود.
- `customer`: کارمزد کامل روی مبلغ پرداخت مشتری افزوده می‌شود.
- `split`: نصف کارمزد روی مبلغ مشتری افزوده می‌شود.
- `default`: تنظیم پیش‌فرض پذیرنده را اعمال می‌کند؛ حذف فیلد یا `null` نیز همین رفتار را دارد.
- `free`: مقدار مجاز API نیست. رایگان‌بودن فقط با تنظیم کارمزد صفر توسط مدیر فعال می‌شود.

اگر کارمزد حساب صفر باشد، هیچ مبلغی رزرو یا کسر نمی‌شود و فیلدهای کارمزد پاسخ صفر خواهند بود.

### محدودیت مبلغ و زمان

- مبلغ پایه فاکتور: حداقل ۱٬۰۰۰ و حداکثر ۵۰۰٬۰۰۰٬۰۰۰ تومان
- کد تطبیق خودکار: ۱ تا ۹۹۹ تومان روی مبلغ نهایی
- مهلت فاکتور: ۵ تا ۱٬۴۴۰ دقیقه
- شارژ کیف پول: حداقل ۱۰٬۰۰۰ و حداکثر ۱۰۰٬۰۰۰٬۰۰۰ تومان

### Callback

برای پرداخت موفق سه تلاش انجام می‌شود: تلاش اول فوری، تلاش دوم ۲ ثانیه پس از پایان تلاش اول و تلاش سوم ۶ ثانیه پس از پایان تلاش دوم. Timeout هر تلاش ۱۲ ثانیه است، Redirect دنبال نمی‌شود و هر پاسخ 2xx موفق محسوب می‌شود. Callback آزمایشی فقط یک تلاش دارد.

### Rate Limit و Sandbox

Rate Limit نسخه 0.5.3 روی پنجره ثابت ۶۰ ثانیه‌ای اجرا می‌شود:

- هر API Key: ۱۲۰ درخواست در دقیقه
- ساخت فاکتور برای هر API Key: ۳۰ درخواست در دقیقه
- هر IP: ۳۰۰ درخواست در دقیقه

پاسخ‌ها هدرهای `X-RateLimit-Limit`، `X-RateLimit-Remaining`، `X-RateLimit-Reset` و `X-RateLimit-Scope` دارند. پاسخ ۴۲۹ علاوه بر این موارد، هدر `Retry-After` برمی‌گرداند. این شمارنده در حافظه هر Process است و با Restart صفر می‌شود؛ در چند Replica سهمیه‌ها مستقل‌اند.

Sandbox مستقل هنوز وجود ندارد؛ فروشگاه یا کلید آزمایشی فقط دسترسی‌ها را جدا می‌کند و همچنان فاکتور واقعی می‌سازد.

### امنیت وبهوک پیامک

توکن واقعی وبهوک پیامک در صفحه مستندات نمایش داده نمی‌شود. URL کامل فقط داخل گفت‌وگوی ربات در مسیر «اتصال و API ← وبهوک پیامک» قابل دریافت است. در صورت افشا، گزینه «تعویض توکن امنیتی وبهوک» توکن قبلی را بلافاصله باطل می‌کند و روی API Keyها یا Secret Callback اثری ندارد.



## نسخه 0.5.7 — بازشدن پایدار صفحه پرداخت

- دکمه‌های پرداخت داخل گفت‌وگوی خصوصی ربات با `Telegram Web App` باز می‌شوند.
- لینک خام از متن اعلان حذف شده تا کاربر ناخواسته Chrome Custom Tab را باز نکند.
- دکمه مستقل «کپی لینک پرداخت» برای ارسال لینک به مشتری اضافه شده است.
- لینک عمومی `/pay/{token}` و قرارداد API بدون تغییر باقی مانده‌اند.
- خطای `ERR_NETWORK_CHANGED` یک خطای سمت مرورگر/شبکه است؛ این نسخه مسیر ورود از خود ربات را به Web App منتقل می‌کند، اما برای لینک‌هایی که بیرون تلگرام یا در مرورگر عادی باز می‌شوند همچنان پایداری اینترنت، VPN، DNS و دامنه میزبان مؤثر است.

## دریافت امن SMS Forwarder

مسیر عمومی زیر در BluePay به صفحه رسمی ناشر در Google Play هدایت می‌شود:

```text
/downloads/sms-forwarder
```

این پروژه عمداً APKهای بازبسته‌بندی‌شده یا ویرایش‌شده را میزبانی نمی‌کند. دکمه دریافت نسخه رسمی در بخش «اتصال و API ← وبهوک پیامک» و مستندات عمومی نمایش داده می‌شود.


## وب‌سایت عمومی نسخه 0.6.0

مسیر `/` اکنون یک لندینگ کامل و واکنش‌گرا برای معرفی BluePay است و شامل نحوه کار، امکانات، نمونه اتصال API، امنیت، سؤالات متداول و دکمه ورود خودکار به ربات می‌شود. مسیر `/telegram` نام کاربری ربات را از Telegram Bot API تشخیص می‌دهد؛ بنابراین متغیر نصب جدیدی لازم نیست.
